# Personal Portfolio Website

A modern and responsive **personal portfolio website built with React.js and Vite** to showcase my frontend development skills, projects, technical abilities, and contact information.

The project is built using reusable React components and demonstrates practical frontend concepts such as **React Hooks, state management, component-based architecture, dynamic rendering, filtering, responsive navigation, and form handling**.

---

## Live Demo

🔗 **Live Deployment:** [[https://your-portfolio-domain.vercel.app]]

---

## Features

* Responsive personal portfolio layout
* Component-based React architecture
* Responsive navigation bar
* Mobile hamburger menu using React state
* Smooth section-based navigation
* "Hire Me" call-to-action
* Dynamic typewriter effect using `useState` and `useEffect`
* Downloadable resume
* About Me section
* Technical skills showcase
* Skills filtering by category
* Reusable Skill Card component
* Featured Projects section
* Reusable Project Card component
* GitHub and Live Demo links for projects
* Controlled contact form using React state
* Required-field form validation
* Contact form success-message UI
* GitHub, LinkedIn, and email links
* Smooth scroll-to-top functionality
* Responsive CSS layouts

## Installation

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Esakkiraja1007/Personal-Portfolio-webpage.git
```

### 2. Navigate to the Project Folder

```bash
cd Personal-Portfolio-webpage
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Vite will start the local development server.

Open the local URL displayed in your terminal in your browser.
